계정 및 데이터 삭제 요청

트래블프레임 계정과 서버에 저장된 앱 데이터를 삭제하는 방법을 안내합니다. 클라우드 백업 데이터는 앱 설정에서 직접 삭제할 수 있고, 계정 삭제 또는 전체 서버 데이터 삭제는 이메일로 요청할 수 있습니다.

1. 백업 데이터 삭제

사진, 편집 이미지, 영상 등 클라우드 백업 데이터는 앱에서 직접 삭제할 수 있습니다.

  • 앱에서 로그인합니다.
  • 설정 탭을 엽니다.
  • 계정 영역의 클라우드 백업 또는 백업 데이터 항목에서 백업 데이터 삭제를 누릅니다.
  • 확인 창에서 삭제를 승인하면 Firebase에 저장된 백업 파일과 백업 기록이 삭제됩니다.

이 작업은 서버에 백업된 데이터만 삭제합니다. 휴대폰 앨범, 다운로드 폴더, 앱 내부 저장소에 남아 있는 로컬 사진, 편집 결과, 영상은 사용자가 기기에서 직접 삭제해야 합니다.

2. 계정 또는 전체 데이터 삭제 요청

계정 삭제, 음악 파일 삭제, 전체 서버 데이터 삭제처럼 앱에서 직접 처리할 수 없는 요청은 메일 본문에 다음 정보를 적어 주세요.

  • 가입 이메일
  • 사용자 UID를 알고 있다면 UID
  • 요청 내용: 계정 삭제, 사용자 음악 삭제, 전체 서버 데이터 삭제 중 선택

3. 삭제되는 데이터

  • Firebase 로그인 계정 정보
  • Firestore에 저장된 사용자 프로필, 설정, 구독 상태, 사용량 및 결제 이벤트 기록
  • 사용자가 클라우드 백업한 사진, 편집 이미지, 영상과 백업 메타데이터
  • 사용자가 마이페이지에 추가한 음악 파일과 음악 메타데이터
  • 앱 기능 제공을 위해 서버에 저장된 사용자별 작업 기록

4. 삭제되지 않을 수 있는 데이터

휴대폰 앨범, 다운로드 폴더, 외부 저장소, 앱 내부 저장소에 저장된 사진과 영상은 서버에서 삭제할 수 없습니다. 결제, 환불, 보안, 법령 준수를 위해 필요한 최소 기록은 관련 법령과 플랫폼 정책에 따라 일정 기간 보관될 수 있습니다.

5. 처리 기간

앱에서 직접 실행한 백업 데이터 삭제는 요청 즉시 처리됩니다. 이메일로 접수한 계정 또는 전체 데이터 삭제는 본인 확인이 완료된 뒤 영업일 기준 7일 이내 처리하는 것을 원칙으로 합니다. 추가 확인이 필요한 경우 이메일로 안내합니다.
