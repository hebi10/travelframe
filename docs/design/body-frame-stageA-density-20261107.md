- 참조: [10개 화면 원본 시안/Android 캡처 비교 기획](https://docs.google.com/document/d/1EEPCjSOLidZloCC2v561nW-W-rU0-BjLVXejztWl_Ps/edit)
- 목표: 정보 밀도와 사진·그래프·저장 영상의 시각적 우선순위를 보정하되 기존 기록·영상·권한·유료 플랜 로직 유지

## 변경 내용

### 1. 설정 — 최소 44dp 터치, 읽기 쉬운 행 구성
- 설정 행 `64→52dp`, 가로/세로 패딩 축소. 행당 반복 보조 설명은 화면에서 기본 숨기되 기존 `accessibilityHint`에 전문 보존.
- 클라우드 백업을 사용할 수 없는 플랜에서는 제한 사유를 계속 표시.
- 6개 설정 그룹, 저장/백업 및 플랜/계정 이동, 저장 모달 및 라디오 선택 동작은 모두 유지.
- 설정 상단의 부연 설명을 짧게 변경. 미사용 복잡한 애니메이션/그림자/색상 추가 없음.

### 2. 수치 기록 — 차트 날짜와 기록 목록 발견성
- 1/3/6개월·전체 기간, 지표 선택, Health Connect, 기록 추가/수정/삭제 모두 유지.
- 그래프 카드에 이 화면 전용 `compact` 표시를 적용. 기존 프로젝트 상세 그래프는 기본 구성 그대로 유지.
- 그래프 아래 `시작/최근`을 실제 기록 날짜(Asia/Seoul)와 함께 표시.
- 프로젝트 안내, 기간/지표 간격 및 시작/현재/변화/기록 4개 요약 카드 높이를 축소.
- 좌우 스크롤 가능한 지표 선택의 스크롤 표시 및 접근성 설명 보강.

### 3. 영상 홈 — 저장 영상 우선
- 저장한 영상이 존재하면 저장 목록을 프로젝트 목록보다 먼저 표시. 저장 영상이 없으면 기존 프로젝트 목록을 먼저 노출하고 빈 영상 안내는 아래에 유지.
- 영상 관리로 이동하는 중복 보조 CTA를 히어로에서 제거. 저장 영상 헤더의 `전체 보기`로 동일 기능 접근 가능.
- 기존 일러스트를 가독성 있게 확대, 설명과 한도 공지 밀도 조정.
- 영상 만들기/프로젝트별 만들기, 비로그인 출력 제한, 영상 목록·삭제·재생 동선 불변.

### 4. 기록 목록 — 사진·진행률 우선
- 프로젝트 커버 너비를 카드 너비의 32%→36%로 조정(108~128dp 제한), 카드 안 기록 메타에 `기록` 라벨 부여.
- 진행률 텍스트 대비와 막대 높이 개선. 제목과 프로젝트 섹션 사이 공백 축소.
- 기존 360dp 1열/560dp 이상 2열 구조, 사진 ID/순서/썸네일, 프로젝트 생성/복원 한도와 바로 촬영 동작 불변.
