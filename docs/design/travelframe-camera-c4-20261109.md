# TravelFrame C4 — 촬영 가이드·기준 사진 조정 UI 개편

기준: `feat/r3-frame-journal-camera-c3-20261109` (PR #142). C4는 **C3 위에 추가되는 후속 독립 PR**로, `main` 직접 변경·배포 없음.

## 목표와 기존 동작 보존

Frame Journal / Body Frame 콘셉트의 촬영 작업 공간은 블랙·차콜 기반. 가이드 설정 시트와 기준 사진 플로팅 패널만 재설계한다.

- 유지: 중앙점·중앙원·십자선·삼각형·사각형·3분할·수평선 7종 가이드, 선 두께 1~5px, 6개 색상, 크기 프리셋과 직접 입력·슬라이더, 표시/숨기기, 위치·모양 조절, 그리드 선 직접 조작.
- 유지: 기준 사진 원본 보존·첫/최근 사진 전환·표시 여부 및 투명도(10~85%)·사진 위치/크기 드래그와 핀치·확인/초기화. 파일 삭제 또는 다른 프로젝트 참조 변경은 기존 흐름을 유지한다.
- 변경 없음: 촬영 이미지 저장·캡처 권한·영상·계정/구독/백업/Play/Firebase 운영 트랙 및 서명.

## 1. 가이드 설정 바텀시트

- 기존 **밝은 반투명 시트**를 촬영 설정(C3)과 동일한 차콜 `#101012`, 반투명 검은 딤 배경, 무채색 선택 테두리로 통일.
- Header: `BODY FRAME / 가이드 설정`, 짧은 목적 설명, 닫기 버튼.
- 구도 선택: `GUIDE_TYPES` 7종을 3열 자동 줄바꿈. 선택한 형태를 체크 표시·선택된 바탕/테두리로 식별.
- 크기 선택: 기존 `GUIDE_SIZE_OPTIONS` 3개를 유지하고 작은 slider에 `dark` 표현만 추가. 타 화면의 `GuideSizeSlider` 기본 스타일은 유지.
- 위치 편집: 그리드=선 위치 조절 / 비그리드=위치·모양 조절 분기 유지; 중앙·초기화·선 설정·완료 조작 버튼은 좁은 폭에서 줄바꿈.
- 선 두께와 6개 색상: 터치 44dp 이상. 색상 칩은 3열 2행 반응형 배치와 체크 아이콘·접근성 색 이름 유지.
- 화면 최대 높이 86%, Safe Area, 내부 ScrollView, 키보드 회피 및 조작 포커스 보존.

## 2. 기준 사진 조정 패널

- 사진 프리뷰를 가리기 쉬운 반투명 패널을 불투명한 차콜 대비 패널로 단순화. 불필요한 컬러 경고·그림자 없음.
- 사진 가이드 헤더에 이동·핀치 사용법과 **원본 사진 보존**을 명시.
- 투명도 slider, 작게/크게/초기화/확인, 이미지 제거/프로젝트 첫·최근 사진 전환 핸들러 유지.
- 긴 버튼은 최대 두 줄·랩 배치로 축소 화면/글꼴 확대 대응. 이미지 제거는 오버레이 표시 해제이므로 빨간 삭제 경고가 아닌 중립 표현.
- 저장 UI는 `removeReferenceOverlay`와 `reopenOverlaySetup`의 `referencePhotoVisible` 동기화 로직 그대로 사용하고 `referenceUri`, 사진 파일과 프로젝트 ID는 유지한다.
