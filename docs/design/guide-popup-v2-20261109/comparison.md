# 사용 가이드 팝업 V2 — 시안/실제 화면 비교

## 비교 방법

Android 원본은1080×2424, density420, 시스템 글자1.0, 앱 기본 글꼴, 다크이다. UI XML의 `app-guide-popup` 실제 경계로 팝업을 추출했다. 시안을 같은 폭으로 비례 축소하며 실제 캡처 픽셀은 크기 변경하지 않았다. 같은 픽셀 크기에서 나란히 보고50% 중첩본으로 위치도 확인한다. 앱용 PNG 원본은 편집하지 않는다.

- 생성 기준: design-reference.png(1122×1402)
- 첫 실제 경계: x47,y637~x1033,y1866 →986×1229px
- 같은 폭의 시안:986×1232px. 높이 차이3px(약1.1dp).
- 초기 비교: comparison-initial.png / overlay-initial.png / metrics-initial.json

## 1차 차이와 보정 계획

| 항목 | 기준 | 첫 실제 결과 | 차이와 수정 |
|---|---|---|---|
| 외곽 크기 | 986×1232 | 986×1229 | 크기 차이는 작음. 내부 조정 후 재측정 |
| 제목 | 굵은 첫 사진 안내 | 700 굵기로 표현 | 대체로 일치, 유지 |
| 헤더·본문·CTA | 굵고 분명한 글자 | 제목에 비해 가늘게 표현 | 선택 글꼴을 유지하고 해당 텍스트 굵기를700으로 보완 |
| 진행 막대 | 밝은 회색, 약4dp | 더 가늘고 어두움 | 높이4dp, 비활성은 muted 토큰으로 보정 |
| 안내 이미지 | 약1.95:1 프레임 | 2:1 프레임으로 조금 더 낮음 | 표시 비율1.95, 원본 비율은 유지하며 검은 여백만 crop |
| 내부 정렬 | 이미지/본문/CTA가 같은 좌우 축 | 같은 축 | 유지. 본문 아래·푸터 패딩을 재조정 |
| 배경 질감 | 생성 시안의 미세 질감 | 단색 네이티브 표면 | 기존 디자인 원칙대로 단색 유지, 남는 차이로 기록 |

## 2차 반영과 재확인

- 헤더·진도·첫 안내 본문·다음 버튼 굵기를 보완했다. 다음/이전 버튼은 계속 네이티브 조작이다.
- 진도 막대는4dp와 muted 색상으로, 이미지 표시 프레임은1.95:1로 맞췄다. 제목 위·본문 아래·푸터의 간격도 보정했다.
- 최종 실제 경계: x47,y636~x1033,y1867 →986×1231px. 같은 폭의 시안986×1232px와 전체 높이 차이는1px(약0.4dp)이다. 이는 외곽 높이 수치이며 전체 화면 픽셀이 일치한다는 뜻이 아니다.
- 결과: comparison-final.png / overlay-final.png / metrics-final.json. 이미지·본문·CTA의 좌우 정렬, 주요 간격과 글자 위계를 육안으로 재확인했다.
- 실제 앱에서1→2→이전→1,1~6단계,완료 후 재보기,상단X닫기 후 재보기,Android뒤로 닫기를 확인했다. 이동·완료·닫기의 저장 흐름은 기존 정책을 유지한다.

## 남는 차이

- 생성 시안의 약한 입자·명암 변화는 평면 디자인 원칙에 따라 실제 UI에 복제하지 않았다.
- 생성 이미지의 글자와 네이티브 Noto Sans KR의 획·안티앨리어싱은 다르다. 실제 UI는 선택 글꼴·접근성 배율을 유지한다.
- 전체 시안을 생성하는 과정에서 도구가 삽입 이미지를 약간 재해석했다. 실제 앱은 별도로 생성한 안내 PNG 원본을 그대로 사용하므로 썸네일·컨트롤의 미세 크기는 시안과 차이가 남는다. 원본 PNG를 시안에 맞추려고 왜곡하지 않는다.

## 작은 화면·큰 글씨와 회귀 확인

- 360dp(density480)·시스템 글자150%: 첫 안내와 긴4단계에서 상단닫기·진도·이전/다음이 본문과 겹치지 않고 접근 가능했다. 줄수 제한으로 본문을 자르지 않았다.
- 4단계 내용을 스크롤한 뒤5단계로 이동해 제목부터 표시되는 것을 확인했다. 캡처: large-first.png, large-metrics.png, large-next-top.png.
- 검증 후 density420·시스템 글자1.0으로 복원했다. 앱의 사진·영상·프로젝트 데이터를 시딩하거나 변경하지 않았다.
- TypeScript, ESLint, 관련 가이드/Stage6/StageC/C6/접근성 공식 회귀 통과. QA Python3파일 문법 검사 통과. 독립 코드 리뷰에서 P0~P2 결함 없음.
- 실제 신규 설치 초기화·ARM64 물리기기·TalkBack 음성 전체 흐름은 수행하지 않았다. 기존 첫 방문/재보기 분리와 저장정책은 관련 회귀로 확인했다.

생성 시안은 실제 실행 화면이 아니며 폰트·질감·삽입 이미지까지 픽셀 일치를 주장하지 않는다.
