# TF-PAY-UX-05 — 플랜 탭·구독 결제 Android QA

## 검증 범위
- 변경 대상: 기존 4탭 유지, 5번째 플랜 탭, Pro/Plus/Expert 혜택 비교, 촬영·기록·영상·백업 진입점, 로그인 전 비교, 로그인 후 선택한 플랜의 결제 모달, 결제 후 기능 복귀
- 보존 대상: `photoId`/sequence/EXIF, 원본 파일, 영상 MP4·인코더, 앱 로컬 및 Firebase 기록, 기존 결제 SKU와 가격, 서버 구매검증, 광고 제거 기구매 복원
- 운영 Google Play/Firebase·결제는 **이 PR에서 실행하지 않음**

## 자동 기능 검증
1. `tests/tf-pay-ux-01~05.test.mjs`와 전체 Node/TypeScript/Expo lint 통과
2. 무료·비로그인·기존 광고 제거·Pro·Plus·Expert 및 만료 상태의 정확한 `PLAN_ENTITLEMENTS` 기준 사용
3. Google Play 상품가격을 못 받으면 결제 요청 금지, Firebase 확인 실패 시 유료 권한 임의 부여 금지
4. 플랜 딥링크의 `returnSource`는 허용된 앱 경로로만 변환하고 외부 URL/임의 사용자 경로 무시
5. Stage13 Android: 360/412/600/750dp × 다크/라이트 × 시스템 글꼴 100/130/150%의 실제 PNG·XML·해시·화면 목록과 `plans` 화면 확인. 비밀키/로그인/실제 계정 데이터 없이 일회용 에뮬레이터 사용

## 물리 Android 기기에서 별도 확인할 사항
- Google Play 내부 테스트의 설치형 ARM64 앱, 테스트 Google 계정 및 로그인/구매 옵션 표시
- 비로그인: 요금제 비교 가능, 구매 시 로그인 후 선택한 플랜 복구
- 서버 확인 실패·상품 조회/네트워크 오류·구매 취소에서 기존 앱 데이터 유지, 중복 결제 불가
- Pro/Plus/Expert 각 신규 라이선스 테스트 구매와 구독 상태/워터마크/광고/프로젝트·백업 한도 반영
- 구매 후 촬영·프로젝트·설정·영상으로 돌아가 실제 작업을 계속할 수 있는지 확인. **특히 영상 생성 중 사진 선택/영상 옵션 드래프트 보존은 에뮬레이터 정적 캡처만으로 보장되지 않으며 물리 기기에서 독립 검증**
- 3요금제 상향/하향 6방향, 재설치 복원, 결제 취소·환불·만료·RTDN 권한 회수
- 360/412/600/750dp 레이아웃, 다크/라이트, 150% 글자, TalkBack 포커스/선택/닫기, Google Play 결제 모달·뒤로가기
- 기존 영구 `ad_remove` 구매는 신규 판매하지 않고 권한 복원 유지
