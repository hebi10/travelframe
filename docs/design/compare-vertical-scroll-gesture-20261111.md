# 전후 비교 영역 세로 스크롤·가로 드래그 분리

- 대상: `features/records/BodyFrameCompareScreen.tsx`.
- 원인: 기존 PanResponder가 터치 시작과 모든 방향의 움직임을 무조건 획득하여 상위 `ScrollView`가 비교 사진 영역의 수직 스크롤을 처리하기 어려움.
- 수정: 터치 시작에는 responder를 획득하지 않음. 이동이 8dp를 초과하고, 좌우 이동이 상하 이동의 1.2배를 초과하는 경우에만 가로 비교 PanResponder 획득.
- 결과 의도: 사진 어느 영역에서든 상하 드래그는 화면 스크롤, 충분히 수평인 드래그만 비교 구분선 이동.
- 보존: 10~90% clamp, 25/50/75% 버튼, 중앙 손잡이, 사진 원본 비율, TalkBack 조절 액션, 비교 모드와 사진 선택, 앱 데이터·버전·기존 Play 배포.
- 정적 자동 검사: `tests/compare-photo-gesture-scroll.test.mjs`에서 수평/수직/대각선 및 소규모 이동 경계, PanResponder 구성, 접근성 제어 검증.
- Android QA: 360/412/600/750dp에서 사진 내부를 세로 드래그하면 페이지 스크롤되고, 가로 드래그는 구분선만 이동하는지 실제 제스처 기반 검증 필요. 단순 스크린샷으로 스크롤 동작을 입증하지 않음.
