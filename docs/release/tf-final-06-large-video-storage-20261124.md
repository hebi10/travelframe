# TF-FINAL-06 — 대량 사진·영상 저장 안전성

- 기준 main 95e60a6238f9f6d66d8bc2cf74d829d311cdb1a4. 전체 사진 원본 staging의 직렬 처리를 유지하고, 사진마다 실제 여유 공간을 확인한다. H.264 5 Mbps + 오디오 및 오버헤드 기반의 예상 출력/앱 저장 중복 공간과 32 MiB 여유 공간을 확보하고, 인코딩 직전 및 실제 영상 저장 직전에 다시 확인한다. 이는 예상치이며 실제 인코더/기기 성능 보장은 아니다.
- 저용량 오류는 다른 URI로 무조건 재시도하지 않는다. 원본 및 이전 영상을 지우지 않는다.
- 각 staging 작업은 취소/시간 초과 후 늦게 끝난 네이티브 복사·다운로드의 임시 목적지를 정리한다. 실제 네이티브 record() 정산까지의 기존 가드는 유지한다.
- 새 영상 보관함 기록 또는 커버 복사 실패 시 생성된 미커밋 복사본만 정리한다. 기존 영상, 원본 촬영 파일과 복구 정책 유지.
- 100/200/365장 모의 파일 경계 테스트, 전 구간 프레임 인덱스, 원본 불변, 직렬 staging, 저용량/취소/시간 초과 및 저장 실패 검증 추가.
- 실제 Android 100/200/365장·FHD·BGM·여유 공간·메모리·시간 측정은 미실행. 최종 개발 SHA에 맞춰 실기기/에뮬레이터 QA를 별도로 수행하며 이 테스트를 실측 성능 수치로 대체하지 않는다. 결제 상품·권한·배포 정책 및 운영 데이터 변경 없음.
