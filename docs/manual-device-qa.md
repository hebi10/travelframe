# 수동 실기기 QA 체크리스트

자동 테스트로 확인하기 어려운 네이티브 흐름은 Android 실기기에서 아래 항목을 직접 확인한다.

## Android 실기기

- 카메라 탭에서 카메라 가이드 버튼을 누르면 라인 가이드와 사진 가이드 선택 모달이 열린다.
- 라인 가이드 설정에서 드래그 이동하기를 누르면 카메라 화면만 남고, 손가락 드래그로 위치가 이동한다.
- 드래그 이동 화면에서 중앙 버튼을 누르면 가이드가 중앙으로 돌아오고, 완료 버튼을 누르면 설정 화면으로 복귀한다.
- 라인 가이드와 사진 가이드를 둘 다 켠 상태에서도 촬영 화면에서 함께 표시된다.
- 촬영 사진 저장 후 MediaLibrary 권한과 앱 내부 사진 목록 저장이 정상 동작한다.
- 사진 편집 저장, 사진 가져오기 저장, 여행클립 이미지 작업물 저장 후 Firebase 백업이 켜져 있으면 자동 백업된다.
- 백업 실패가 발생한 뒤 설정 화면에서 실패한 백업 다시 시도 버튼으로 재업로드를 시도할 수 있다.
- 백업 기능을 켤 때 기존 Firebase 백업이 있으면 현재 기기 데이터 백업, 클라우드 데이터 불러오기, 나중에 선택 중에서 고를 수 있다.
- 클라우드 데이터 불러오기 선택 시 현재 기기 데이터 변경 및 자동 병합 없음 경고가 표시된다.
- 백업 데이터 삭제는 Firebase 백업 데이터만 삭제하고 기기 안의 로컬 사진, 작업물, 영상은 유지한다.
- 여행클립 MP4 저장 후 갤러리에 저장됐다는 완료 문구가 표시된다.
- 구독 계정에서는 광고 제거, 여행클립 MP4 저장, 클라우드 백업 권한이 함께 적용된다.
