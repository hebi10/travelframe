# 바디 프레임 수동 실기기 QA 체크리스트

자동 테스트로 확인하기 어려운 네이티브 흐름과 최종 디자인은 Android 실기기에서 아래 항목을 직접 확인한다.

## Android 핵심 플로우

- 앱 런처에서 검정 배경의 BF 모노그램 아이콘이 표시되고 Adaptive Icon에서 BF가 잘리지 않는다.
- 새 설치 후 첫 카메라 진입에서 환영 안내가 1회만 표시되고 `시작하기`로 바로 닫을 수 있다.
- 촬영 화면 상단은 현재 프로젝트와 촬영 도구가 중심이며 카메라 화면을 과도하게 가리지 않는다.
- 첫 사진 전에는 `첫 사진을 찍어 기준을 만들어주세요.` 안내가 표시된다.
- 첫 사진 저장 후 다음 촬영부터 first/latest 정책에 맞는 기준 사진이 반투명하게 표시된다.
- 하단 기본 동선에서 최근 사진 / 셔터 / 기준 사진 투명도에 접근할 수 있다.
- 촬영 도구에서 라인, 기준 사진, 색감, 확대, 라이트, 전후면 카메라 전환을 사용할 수 있다.
- 기록 탭은 프로젝트를 2열 9:16 Photo Grid로 보여주고 대표 사진, 진행률, 예상 영상 길이가 정상 표시된다.
- 프로젝트 상세는 진행률, 시작일, 변화 영상 길이, 오늘 사진 찍기, 3열 기록 Grid 순으로 표시된다.
- 프로젝트 설정 Bottom Sheet에서 이름, 목표 기록 수, first/latest 기준 사진, 프로젝트 보관이 정상 동작한다.
- 변화 영상 화면은 사진 수 / 사진 간격 / 영상 길이 / 화질 / 화면 비율을 표시한다.
- 변화 영상은 사진 1장당 0.1초, 30fps 정책으로 생성되고 갤러리에 저장된다.
- 플랜 한도를 초과한 경우에만 제한 안내와 플랜 보기 CTA가 표시된다.
- 설정 화면은 촬영 / 저장 및 백업 / 변화 영상 / 화면 / 계정 및 플랜 / 정보 및 개인정보 6개 그룹으로 표시된다.
- 설정의 사용 가이드에서 현재 Body Frame 안내를 다시 표시할 수 있다.
- 계정 화면에서 현재 플랜 / 현재 프로젝트 / 현재 기록 / 클라우드 백업 / 다음 갱신일을 확인할 수 있다.
- Google Play 구매와 구매 복원이 정상 동작하고 서버 검증된 entitlement가 반영된다.
- 클라우드 백업을 켜고 끄거나 백업 데이터를 불러올 수 있으며 로컬 기록은 임의 삭제되지 않는다.
- 계정 및 데이터 삭제 요청과 개인정보처리방침 진입이 정상 동작한다.
- `/advanced-settings`, `/legacy-studio` 호환 라우트는 기존 데이터를 위해 유지되지만 기본 탭과 설정 홈에서는 직접 노출되지 않는다.

## Android 표시/접근성 QA

- 360dp급 작은 화면에서 하단 탭, 촬영 도구, Bottom Sheet, Modal의 확인/취소 버튼이 화면 밖으로 잘리지 않는다.
- 시스템 글꼴 크기와 표시 크기를 크게 설정해도 핵심 텍스트가 겹치지 않고 주요 CTA에 접근할 수 있다.
- 모든 핵심 터치 컨트롤은 최소 44×44dp의 터치 영역을 확보한다.
- 상태바, 카메라 상단 영역, Bottom Sheet가 Safe Area와 겹치지 않는다.
- 다크 모드에서 배경 / 카드 / 텍스트 / 비활성 상태의 대비가 충분하다.
- 라이트 모드에서도 사진, 진행률, CTA의 정보 위계가 유지된다.
- 폴더블 또는 넓은 화면에서 콘텐츠가 과도하게 늘어나거나 한쪽으로 치우치지 않는다.
- 촬영 / 기록 / 프로젝트 상세 / 영상 / 설정 / 계정 화면에 불필요한 그림자, 그라디언트, 과도한 radius가 추가되지 않는다.
- 핵심 Body Frame 화면에서 특정 한쪽 면만 사용하는 구분용 border가 보이지 않는다.
- 사용자에게 노출되는 주요 문구에 TravelFrame, 여행, 여행클립 등 이전 제품 용어가 표시되지 않는다.

## 출시 전 브랜드 QA

- `assets/icons/app-icon.png`은 BF 모노그램 v2 1024×1024 앱 아이콘이다.
- `assets/icons/adaptive-icon.png`은 투명 배경의 BF Adaptive foreground v2 1024×1024이다.
- Android Adaptive background는 `#0B0B0C`를 사용한다.
- Play Console 앱 아이콘과 실제 설치 앱의 런처 아이콘이 동일한 BF 방향인지 확인한다.
- v2 패키지에 별도 splash 최종안이 없으므로 splash를 임의로 BF 앱 아이콘으로 대체하지 않는다.
