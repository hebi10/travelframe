# 바디 프레임 수동 실기기 QA 체크리스트

자동 테스트로 확인하기 어려운 네이티브 흐름과 최종 디자인은 Android 실기기에서 아래 항목을 직접 확인한다.

## Android 핵심 플로우

- 앱 런처에서 검정 배경의 BF 모노그램 아이콘이 표시되고 Adaptive Icon에서 BF가 잘리지 않는다.
- 새 설치 후 첫 카메라 진입에서 환영 안내가 1회만 표시되고 `시작하기`로 바로 닫을 수 있다.
- 촬영 화면 상단은 현재 프로젝트와 촬영 도구가 중심이며 카메라 화면을 과도하게 가리지 않는다.
- 첫 사진 전에는 `첫 사진을 찍어 기준을 만들어주세요.` 안내가 표시된다.
- 첫 사진 저장 후 다음 촬영부터 first/latest 정책에 맞는 기준 사진이 반투명하게 표시된다.
- 하단 기본 동선에서 최근 사진 / 셔터 / 기준 사진 투명도에 접근할 수 있다.
- 촬영 도구에서 라인, 기준 사진, 색감, 확대, 라이트, 전후면 카메라 전환을 사용할 수 있다.
- 프로젝트 설정의 `촬영 설정 기억`을 켠 프로젝트는 카메라 방향 / 비율 / 확대 / 노출 / 색감이 촬영 성공 후 저장되고 다음 진입에 복원된다.
- 서로 다른 프로젝트 A/B에서 다른 확대·노출·색감을 저장한 뒤 전환해도 각 프로젝트 값이 독립적으로 복원된다.
- `촬영 설정 기억`을 끈 프로젝트는 저장된 프로젝트 촬영 조건을 적용하지 않고 기존 전역 카메라 설정으로 동작한다.
- 프로젝트 촬영 설정 복원 시 라이트와 타이머가 자동으로 켜지거나 복원되지 않는다.
- 프로젝트 설정의 `자세 맞춤 도움`은 기본 OFF이며 사용자가 직접 켜야 동작한다.
- 첫 사진이 없는 프로젝트에서는 자세 분석을 실행하지 않고 첫 기록 이후 사용할 수 있다는 안내만 표시한다.
- 기준 사진이 있는 프로젝트에서 자세 맞춤 도움을 켜면 왼쪽/오른쪽 이동, 가까이/멀리, 어깨 높이 안내가 한 줄로 표시된다.
- 위치가 맞았을 때 `위치가 맞았습니다.` 안내와 짧은 햅틱이 1회 발생하며 화면에 skeleton 전체를 그리지 않는다.
- 자세 맞춤 도움을 끄면 Preview Snapshot/ML Kit 분석이 실행되지 않고 기존 기준 사진 오버레이와 촬영 동작만 유지된다.
- 자세 분석이 실패하거나 미지원 상태여도 셔터, 기준 사진, 저장, 프로젝트 전환 기능은 계속 사용할 수 있다.
- 장시간 촬영 화면에서 자세 맞춤을 켠 상태로 발열, 프리뷰 끊김, 배터리 소모를 확인하고 약 1초 주기 분석이 촬영을 방해하지 않는지 확인한다.
- 분석용 프리뷰 스냅샷이 사진 보관함이나 앱 기록에 남지 않고 서버/클라우드로 업로드되지 않는지 확인한다.
- 기록 탭은 프로젝트를 2열 3:4 Photo Grid로 보여주고 대표 사진, 진행률, 예상 영상 길이가 정상 표시된다.
- 프로젝트 상세는 진행률, 시작일, 변화 영상 길이, 오늘 사진 찍기, 3열 기록 Grid 순으로 표시된다.
- 프로젝트 상세의 `사진 추가`에서 앨범 사진을 여러 장 선택하면 현재 프로젝트에 다음 기록 순서로 저장된다.
- 프로젝트 사진 한도에 도달한 경우 앨범 가져오기가 차단되고 현재 플랜 한도 안내가 표시된다.
- 프로젝트 상세의 `순서 조정` 또는 사진 길게 누르기로 전체 화면 정렬 모드가 열리고, 한 화면에 여러 사진이 보이는 5~7열 compact Grid가 표시된다.
- 정렬 모드에서 사진을 약 0.3초 길게 누른 뒤 드래그하면 위치를 옮길 수 있고 저장 후 #1부터 순서가 다시 부여된다.
- 순서 변경 후 기준 사진 first/latest와 변화 영상 재생 순서가 새 sequence를 따르며 사진에 연결된 수치 기록의 sequence도 함께 갱신된다.
- 프로젝트 상세의 사진을 누르면 다크 Body Frame 기록 상세 화면으로 연결되고 프로젝트명 / 기록 번호 / 촬영일이 표시된다.
- 프로젝트 상세의 수치 그래프에서 전체 보기를 누르면 수치 기록 전체 화면으로 이동한다.
- 수치 기록 전체 화면에서 활성화된 몸무게 / 체지방률 / 골격근량 / 허리둘레를 전환할 수 있다.
- 각 수치에서 현재값 / 시작 대비 변화량 / 기록 횟수 / 전체 기간 변화선을 확인할 수 있다.
- 기록 목록에서 수치를 수정·삭제할 수 있고 연결된 기록은 사진 상세로 이동할 수 있다.
- 사진과 연결되지 않은 수치 기록도 추가·수정·삭제할 수 있다.
- Stage 9-6 수치 기록은 계속 Local Only이며 클라우드/Health Connect 접근이 발생하지 않는다.
- 프로젝트 사진 상세에서 삭제 후 해당 프로젝트로 돌아가며, 프로젝트 없는 레거시 사진은 기록 탭으로 돌아간다.
- 사진 상세에서 핸드폰 앨범 저장과 로그인 기반 사진 편집 기능이 기존과 동일하게 동작한다.
- 프로젝트 설정에서 수치 기록을 켜고 몸무게 / 체지방률 / 골격근량 / 허리둘레 중 원하는 항목만 선택할 수 있다.
- 수치 기록을 사용하지 않는 프로젝트는 기존 사진 촬영·상세 UX와 동일하게 동작한다.
- 사진 상세의 수치 기록 추가/수정/삭제가 정상 동작하며 값은 현재 기기에만 저장된다.
- 수치 기록을 사용하는 프로젝트 상세 상단에 대표 수치 카드가 표시되고 현재값 / 시작 대비 변화량 / 기록 횟수를 확인할 수 있다.
- 대표 수치 기록이 0개면 수치 기록 추가 CTA, 1개면 다음 기록 안내, 2개 이상이면 미니 변화 선이 표시된다.
- 대표 수치를 바꾸면 프로젝트 상세의 미니 그래프도 해당 수치로 변경된다.
- 사진을 삭제해도 연결된 수치 기록 자체는 유지되고 사진 연결만 해제된다.
- 촬영 후 기록 제안을 켠 프로젝트만 저장 완료 안내에 `수치 기록` 액션이 표시된다.
- 프로젝트 설정 Bottom Sheet에서 이름, 목표 기록 수, first/latest 기준 사진, 프로젝트 보관이 정상 동작한다.
- 변화 영상 화면은 사진 수 / 사진 간격 / 영상 길이 / 화질 / 화면 비율 / 텍스트 옵션을 표시한다.
- 변화 영상의 텍스트 기본값은 `없음`이며 날짜 / 몸무게 / 체지방률 / 자유 텍스트를 각각 선택할 수 있다.
- 날짜를 켜면 사진별 날짜가 `26.09.22` 형식으로 표시되고, 연결된 수치 기록이 있으면 몸무게와 체지방률이 각각 `72.4kg`, `18.2%` 형식으로 표시된다.
- 텍스트 위치는 좌측 상단 / 우측 상단 / 좌측 하단 / 우측 하단 중 선택할 수 있고 프리뷰와 완성 MP4가 동일하게 표시된다.
- 무료 플랜 워터마크와 우측 하단 텍스트를 함께 사용하면 텍스트가 워터마크 위로 이동해 겹치지 않는다.
- 변화 영상은 사진 1장당 0.1초, 30fps 정책으로 생성되고 갤러리에 저장된다.
- 플랜 한도를 초과한 경우에만 제한 안내와 플랜 보기 CTA가 표시된다.
- 설정 화면은 촬영 / 저장 및 백업 / 변화 영상 / 화면 / 계정 및 플랜 / 정보 및 개인정보 6개 그룹으로 표시된다.
- 설정의 사용 가이드에서 현재 Body Frame 안내를 다시 표시할 수 있다.
- 계정 화면에서 현재 플랜 / 현재 프로젝트 / 현재 기록 / 클라우드 백업 / 다음 갱신일을 확인할 수 있다.
- Google Play 구매와 구매 복원이 정상 동작하고 서버 검증된 entitlement가 반영된다.
- 클라우드 백업을 켜고 끄거나 백업 데이터를 불러올 수 있으며 로컬 기록은 임의 삭제되지 않는다.
- 계정 및 데이터 삭제 요청과 개인정보처리방침 진입이 정상 동작한다.
- 수치 기록을 사용하는 프로젝트에서 Health Connect 카드는 사용자가 직접 연결할 때만 권한을 요청한다.
- Health Connect 연결 시 몸무게와 체지방률 읽기 권한만 표시되고 쓰기 / 백그라운드 / 30일 초과 과거 데이터 권한을 요청하지 않는다.
- 권한 허용 후 최신 기록 확인을 누르면 최근 30일의 몸무게·체지방률 후보만 표시된다.
- Health Connect 후보를 확인한 뒤 가져오기를 눌러야 로컬 수치 기록에 추가되며 자동 동기화되지 않는다.
- 같은 Health Connect 기록을 다시 가져오면 중복 수치 기록이 생성되지 않는다.
- Health Connect에서 가져온 기록은 수치 기록 목록에 출처가 표시되고 기존 그래프에 정상 반영된다.
- Health Connect 권한 거부·해제·미지원 기기에서도 수동 수치 기록 기능은 정상 동작한다.
- `/advanced-settings`, `/legacy-studio` 호환 라우트는 기존 데이터를 위해 유지되지만 기본 탭과 설정 홈에서는 직접 노출되지 않는다.

## Android 표시/접근성 QA

- 360dp급 작은 화면에서 하단 탭, 촬영 도구, Bottom Sheet, Modal의 확인/취소 버튼이 화면 밖으로 잘리지 않는다.
- 시스템 글꼴 크기와 표시 크기를 크게 설정해도 핵심 텍스트가 겹치지 않고 주요 CTA에 접근할 수 있다.
- 시스템 글꼴 크기 100% / 약 130% / 약 150%에서 기록, 프로젝트 상세, 촬영 도구, 영상, 설정 화면을 확인한다.
- 프로젝트 카드, 사진 Grid, 촬영 보조 라벨 등 핵심 사용자 표시 텍스트에 9~10px급 초소형 문구가 남아 있지 않은지 확인한다.
- 페이지 제목과 프로젝트명이 사진 콘텐츠보다 과도하게 크게 느껴지지 않는지 확인한다.
- 모든 핵심 터치 컨트롤은 최소 44×44dp의 터치 영역을 확보한다.
- 상태바, 카메라 상단 영역, Bottom Sheet가 Safe Area와 겹치지 않는다.
- 다크 모드에서 배경 / 카드 / 텍스트 / 비활성 상태의 대비가 충분하다.
- 라이트 모드에서도 사진, 진행률, CTA의 정보 위계가 유지된다.
- 폴더블 또는 넓은 화면에서 콘텐츠가 과도하게 늘어나거나 한쪽으로 치우치지 않는다.
- 촬영 / 기록 / 프로젝트 상세 / 영상 / 설정 / 계정 화면에 불필요한 그림자, 그라디언트, 과도한 radius가 추가되지 않는다.
- 핵심 Body Frame 화면에서 특정 한쪽 면만 사용하는 구분용 border가 보이지 않는다.
- 사용자에게 노출되는 주요 문구에 TravelFrame, 여행, 여행클립 등 이전 제품 용어가 표시되지 않는다.

## 출시 전 브랜드 QA

- `assets/icons/app-icon.png`은 승인된 인물 윤곽·촬영 프레임·라임 포인트의 1024×1024 앱 아이콘이다.
- `assets/icons/adaptive-icon.png`은 승인된 심볼에 Android 안전 여백을 적용한 1024×1024 이미지다.
- Android Adaptive background는 `#151719`를 사용한다.
- 실제 설치 앱의 런처 아이콘이 원형·둥근 사각형 마스크에서도 잘리지 않는지 확인한다.
- 시작 화면도 동일한 심볼인지 확인한다. Play Console 이미지는 별도 업로드가 필요하다.
