# Security hardening

사용자 승인 범위: 2026-09-20 보안 점검 결과 보완. 커밋·배포·기존 데이터 삭제 제외.

1. 기존 기록 소유 계정을 명시적으로 확정하고 다른 계정 및 로그아웃 상태의 접근 차단. 무소유 기록 자동 업로드 금지. 지연된 이전 사용자 구독 조회 무시.
2. Firebase Storage 미디어는 본인 UID/버킷을 검증하여 인증 헤더로 다운로드. 화면에는 로컬 캐시만 전달. 새 업로드만 privateDownload 프로토콜로 다운로드 토큰 폐기.
3. Google Play 구매 검증에 UID별 서버 호출 제한·동시 중복 방지·짧은 활성 구매 캐시 적용. RTDN 갱신은 항상 검증.
4. 호환 의존성 패치 및 동적 보안 회귀 테스트, 타입체크, lint, 서버 구문 검사.
5. 구버전 호환성을 위해 기존 파일의 토큰 폐기와 App Check 강제 적용은 별도 운영 전환으로 문서화. 서버 배포와 새 Android 앱 설치 전에는 운영 반영 완료로 간주하지 않음.

계정 보관함은 이번 변경에서 기기당 한 소유 계정으로 제한한다. 계정별 병렬 보관함을 도입하지 않으며 모든 기존 원본은 유지한다.
