# 촬영 탭 UI V2 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 독립 파일은 병렬 구현하고 메인이 diff를 검토한다. 사용자 지시에 따라 커밋·푸시·배포 단계는 없다.

**Goal:** 촬영 메인과 모든 연결 도구·모달을 생성 시안 기준으로 정돈하고 실제 기능과 큰 글씨 접근성을 확인한다.
**Architecture:** 기존 RN 화면·모달·플로팅 도구를 유지하고 촬영 범위 스타일을 수정한다. 프로젝트 공통 헤더/푸터는 선택적 촬영 typography prop으로만 적용한다. 네이티브 줌 세션과 저장 큐는 유지한다.
**Tech Stack:** Expo55, RN0.83.6, TypeScript, VisionCamera5.1.1, 기존 AppText/Feather.
**Spec:** docs/superpowers/specs/2026-11-10-camera-ui-v2-design.md

## Global Constraints
- 사용자 사진·영상·프로젝트·설정 보존. 실제 생성·설정 변경·권한 QA는 신규 AVD5556만 사용.
- 기존 프로젝트/플랜/저장 정책과 각 설정의 세션/영속 저장 구분 보존.
- 최소44dp 터치, 가용 높이86% 모달, 큰 글씨에는 자연 높이 확장, 헤더·주요 CTA 고정.
- 일반 테스트는 공식 `npm.cmd test -- <파일명 필터>` 실행. 기존 CRLF 호환 preload 유지.
- 기존 미커밋 가이드 V2·줌 비활성 예외 수정 보존, 임의 파일 삭제/커밋 금지.

## 시안 분석 및 반영 결정
기준: docs/design/camera-ui-v2/design-main.png, design-sheets.png(4열), design-tools.png(4열). built-in image_gen 생성, 프롬프트 JSON 보관.
- 메인: 프로젝트 헤더의 기존86dp 높이를48dp 최소+명시적 글자 줄높이로 줄인다. 둥근12dp 표면·정렬된 하단52/68/72dp 컨트롤 채택. 카메라 영상/아이콘/컨트롤을 이미지로 붙이지 않는다.
- 시트: compact 제목·설명·구분선·3+2 도구 타일과 고정 닫기를 채택. 시안의 가이드 색상 임의 보라/오렌지·추가 +/-버튼은 생성 오류이므로 기존6색과 직접입력 유지. 시트 뒷배경의 구형 큰 헤더는 메인 시안 기준으로 보정.
- 도구: 사진/색감/확대/조명 모두12dp 표면·명시적 줄높이·같은44dp 닫기 스타일. 사진의 확인은 편집 종료+잠금이며 취소·롤백을 만들지 않는다. 색감의 초기화/슬롯저장은 그대로 유지. 확대/조명 닫기는 값 변경 없이 패널만 종료.
- 시안의 실시간 영상/시간/폰트·세부 픽셀은 생성형 표현이므로 실제 네이티브 결과와 차이를 기록한다. 시안에 있는 미지원3/5/10x는 기기에서 지원할 때만 표시한다.

## Review Focus
1. 360dp/150%에서 사진 설명/두 줄 액션이 프리뷰와 탭을 침범하지 않는지 확인.
2. 가이드 헤더 긴 설명/입력키보드에서도 닫기·입력·완료가 접근 가능해야 한다.
3. 확대/조명 닫기 뒤 값 유지·탭/백그라운드 복귀·전후면이 예외 없이 동작해야 한다.
4. 저장 플랜 차단의 실제 disabled와 접근성 disabled가 일치해야 한다.
5. 카메라 기기 min/max에 의해 프리셋이 같은 값으로 clamp되어 여러 개 선택되지 않아야 한다.
