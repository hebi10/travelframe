## 2. 디자인 기획

기존 모노톤 팔레트와 10dp 모달 반경을 유지하며 카드 안의 한 가지 행동을 강조한다. 작은 수정안과 전체 폭 CTA를 갖춘 안내 카드안을 비교해, 후자를 이번 구현 방향으로 선택한다.

1. 헤더: `사용 가이드`, `1 / 6`, 오른쪽 상단 44dp 닫기 아이콘. 닫기 접근성 이름은 명확히 제공한다.
2. 진행 표시: 같은 폭의 가는 막대 6개, 현재까지 밝게 표시. 숫자 진도와 함께 제공하므로 색만으로 구분하지 않는다.
3. 제목: `첫 사진을 남겨 보세요`, 24sp/32sp. 작은 화면·큰 글씨에서 제한 없이 줄바꿈한다.
4. 안내 이미지: 실제 촬영의 갤러리·셔터·투명도만 확대하고 바닥 여백과 탭 바를 제거한다. 이미지 생성 도구로 16:9 PNG를 만든다.
5. 본문: `프로젝트를 고른 뒤 첫 사진을 촬영하세요. 다음 촬영에는 기준 사진을 겹쳐 볼 수 있어요.` 기본 글씨에서 2~3줄을 목표로 하고 자르지 않는다.
6. 푸터: `다음`을 전체 폭 48dp 버튼으로 제공. 이후 단계는 `이전`과 더 넓은 `다음/완료`를 배치한다. 닫기는 공통 헤더에 둔다.

기준 시안은 팝업 자체의 정면 이미지(약 376×484dp 비율)를 생성한다. 바깥 휴대전화 프레임·설정 화면·새 기능은 생성하지 않는다. 색상은 surface #1A1A1D, text #F5F5F5, muted #A0A0A6, line #323437, primary #F5F5F5, onPrimary #111111.
