# 촬영 탭 및 연결 모달 디자인 V2

## 목적과 범위
사용자가 승인한 가이드 팝업 V2와 같은 절차로 촬영 탭의 시각적 완성도와 조작 일관성을 개선한다. 기존 RN/Expo/VisionCamera와 저장·플랜·프로젝트·기준사진 정책을 유지한다. 사용자 위임에 따라 메인 에이전트가 디자인 선택과 구현을 진행한다. 커밋·푸시·배포는 하지 않는다.

## 근거
- 작업 시작 Git fetch/pull 성공, origin/main 및 HEAD 4ca8b4a. 기존 미커밋 가이드 V2·줌 세션 수정 보존.
- Google Drive [11/07 상세 검토](https://docs.google.com/document/d/1EEPCjSOLidZloCC2v561nW-W-rU0-BjLVXejztWl_Ps/edit)와 [11/08 FrameJournal R0](https://docs.google.com/document/d/1msQm83e0g_YKp7c7LDgs2pX9moSanQc1jgd6wgWUh4M/edit), 로컬 C1–C7 계획의 프리뷰 우선·흑백·44dp 터치 정책.
- 세 병렬 분석: CameraScreen/도구, 프로젝트 흐름, QA/데이터 안전성. 카메라 공식 회귀 61개 파일 통과.

## 접근 방식
기존 촬영 화면과 도구의 구조를 유지하고 타이포그래피·간격·표면·선택 상태를 일관되게 정돈한다. 모든 도구를 새 대형 모달로 옮기는 방식은 프리뷰와 제스처 동작을 바꾸므로 선택하지 않는다. 카메라 화면은 테마에 관계없이 어두운 프리뷰용 UI, 프로젝트 선택/생성은 기존 테마 토큰을 따른다.

## 표면 목록과 보존 동작
1. 촬영 메인: 계정/프로젝트/설정, 프리뷰/초점/노출, 촬영 상태, 갤러리/셔터/투명도, 4개 하단 탭.
2. 프로젝트 선택·생성: 선택 즉시 반영, 활성 항목/진행, 목표 100/365/직접, 기준 첫/최근 사진, 잠금·오류·고정 CTA·키보드.
3. 촬영 설정: 도구5개, 방향, 타이머, 플래시/손전등, 품질, 6비율, 저장 대상, 소리, 가이드, 햅틱. 전체 스크롤+고정 헤더.
4. 라인 가이드: 7종류, 크기 프리셋/직접입력/슬라이더, 위치/모양·격자편집, 두께·색상·표시.
5. 사진 가이드: 위치/핀치, 투명도, 작게/크게/초기화/확인, 이미지 표시 제거, 프로젝트 첫/최근 전환. 원본은 유지한다.
6. 색감: 5슬롯/6슬라이더, 초기화와 슬롯저장 구분, 닫기.
7. 확대/조명: 기기 지원 프리셋과 현재값, 전면 라이트 비활성 이유, 새 명시적 닫기.
8. 권한/오류/저장중/카운트다운/한도/자세정렬: 기존 안내·재연결·대체 저장·라이프사이클 유지.
9. 연결 라우트 /account, /studio(기록·프로젝트 관리), /photo/[id]는 진입을 확인한다. 기록 탭 전용 프로젝트 상세/수치 편집 전체 재설계는 범위 밖이다. 프로젝트 상세의 기준 전환 시 다른 미저장 초안 초기화 가능성은 별도 발견 사항이며 이번 카메라 UI 변경에 섞지 않는다.

연결 경로 확인 정정(2026-11-10): 원설계의 /projects 표기는 실제 프로젝트 관리 진입 경로인 /studio로 정정했다. 기존 설계의 기능·검증 범위는 유지한다.

## 디자인 기준
- 차콜 #101012/#18181B, 흰색 기본 글자, 회색 보조, 기존 라임은 안내 강조에만 사용.
- 상단 프로젝트 48dp 최소, 제목14/18·메타11/14, 좌우44dp 아이콘, 큰 글씨에는 자연 높이 확장.
- 모달 radius12, 가용 영역 높이 최대86%, 바깥14dp·안쪽16dp, 고정 제목/닫기44dp, 본문만 스크롤. 제목20/28·굵기700, 본문14/20·보조12/18.
- 촬영 도구는 3+2 그리드, 선택은 흰 테두리/밝은 차콜. 컨트롤44dp 이상, 줄바꿈·큰 글씨 허용.
- 편집 패널도 제목/현재값/닫기/본문의 같은 순서. 사진 가이드 확인은 변경 적용, 색감 저장은 슬롯 저장이라는 의미 유지.
- Noto 폰트의 과도한 기본 높이를 피하도록 명시적인 lineHeight 및 includeFontPadding:false를 해당 촬영 스타일에 적용한다. 앱 전역 폰트는 바꾸지 않는다.

## 이미지·검증
실제 변경 전 캡처를 참고해 이미지 생성 기능으로 메인·모달·도구 시안을 만든다. 생성물은 문서용 기준이며 실제 버튼은 네이티브로 구현한다. 이미지/프롬프트를 docs/design/camera-ui-v2에 보존한 후 분석 기반 작업 계획을 쓴다.

실제 비교는 1080×2424/420dpi/글꼴100%의 네이티브 캡처와 같은 상태의 시안 프레임을 같은 너비로 정규화한다. 동적 프리뷰·폰트 렌더러·생성형 텍스트 차이는 숨기지 않는다. 변경 전/초기/보정 후·XML·비교표를 보존한다. 360dp/150%에서 모달·사진·색감·확대·조명·프로젝트·키보드 접근성을 별도 점검한다.

실제 촬영·설정 저장·권한 변경은 별도 신규 QA AVD(5556)에서만 한다. 기존 Pixel_9(5554)에서는 보기/열기/닫기만 수행하고 사진2장과0.2초영상/설정을 보존한다. 기존 seed 스크립트는 사용자 기기에 실행하지 않는다.
