# Body Frame UI image assets

This folder contains transparent PNGs adapted from the independently supplied Body Frame UI asset pack.

- `illustrations/empty-project.png`: local empty-project state
- `illustrations/empty-videos.png`: local empty-video state

These are decorative UI illustrations only. They are not user photo records, are never written to the photo library or uploaded as customer data, and do not replace the existing Play Store launcher icon.

The complete 142-file design source package is maintained separately. This commit intentionally bundles only the optimized illustrations used by the React Native screens.

- `illustrations/empty-photos.png`: no photos recorded in a project
- `illustrations/empty-metrics.png`: no body measurements recorded

## Onboarding illustrations

- `illustrations/feature-capture.png`: welcome and camera setup
- `illustrations/feature-records.png`: project records overview
- `illustrations/feature-compare.png`: photo-alignment guidance
- `illustrations/feature-video.png`: progress video creation

The illustrations are rendered as static local UI resources. These images must never replace project photographs or the approved launcher artwork.
